# Support

Start with the [documentation](https://omenien.github.io/omena-css/) and
[troubleshooting guide](docs/troubleshooting.md).

Use a GitHub issue for:

- a reproducible product defect;
- a focused feature proposal;
- a documentation error tied to current behavior.

Include the Omena version, host surface, operating system, smallest input, exact
command or setting, actual output, and expected output. Search existing issues
before filing a new one.

Use [GitHub private vulnerability reporting](SECURITY.md) for security matters.
Do not place credentials, private repositories, or sensitive source in an
issue.
