# Omena documentation

Omena is a semantic CSS-family platform for CSS Modules, Sass, editor tooling,
and evidence-aware build automation. Start with a working command, then follow
the path that matches what you are trying to accomplish.

## Start here

- [Getting started](./getting-started.md) installs the CLI and configures a workspace.
- [Browser playground](./playground.mdx) runs the real Rust engine locally through WASM.
- [VS Code extension](./vscode-extension.md) connects editor features to the same engine.
- [SDK workflows](./sdk.md) cover NAPI, WASM, CLI, and LSP integration.

## How these docs stay accurate

Generated reference pages are rendered from product contracts. Public code
examples that carry an executable fixture are run in CI; other examples are
typechecked or reviewed with the site build. Release metadata is validated
against an immutable release manifest. Every page also declares whether its
source is authored, generated, or hybrid so readers and contributors know where
a correction belongs.
