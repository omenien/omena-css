# Support

Use GitHub issues for reproducible product defects and focused feature
proposals. Search existing issues first and include the affected Omena version,
host surface, smallest input, exact command or setting, and observed output.

General debugging starts with [Troubleshooting](../troubleshooting.md).
Architecture and contribution questions should include the relevant product
surface rather than only a crate name.

Do not disclose a vulnerability in a public issue. Follow the private process
in the repository [security policy](../../SECURITY.md).
